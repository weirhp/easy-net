开启后会启动需要管理员权限的后台网络接管服务。下方列表中的应用，无论已经运行还是稍后启动，其新建连接都会按配置走代理；服务异常退出时会自动重启。

与桌面快捷方式的区别：快捷方式只负责以 Hook 或浏览器原生代理参数启动单个应用，不要求本页接管服务常驻；自动接管无需从快捷方式启动。两者可以同时开启，连接到代理服务器的流量会被直连放行，不会形成重复代理。

浏览器建议：Chrome/Edge 优先使用本页创建的桌面快捷方式，它会让 SOCKS5 在代理端解析域名，可避开本机 DNS 污染。WinDivert 仍可使用，适合接管已运行的窗口；但它工作在 IP 层，若系统 DNS 已返回错误地址，接管本身无法恢复原域名，建议同时启用浏览器“安全 DNS”。
